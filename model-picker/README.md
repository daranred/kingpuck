# Plain-English Model Picker

A standalone page (not part of the KingPuck site build) that helps non-experts choose AI models.
Set a monthly budget, how much you'll use text, images, video and 3D, and how much quality matters.
It scores every model 0–100 for quality, cost and value within its category, shows a short review,
and recommends one setup that fits the budget.

Open `index.html` in a browser. No build step.

- Prices: pay-as-you-go API rates gathered in early October 2026 (sources linked in the page footer). Update the `CATS` list in `index.html` when prices change.
- Quality scores and reviews are editorial estimates. Viewers can override quality scores in the page; overrides are saved in their browser only.
